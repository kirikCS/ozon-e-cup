## 3. Теория: что именно оптимизирует RMSLE

Два результата, определившие всю дальнейшую работу.

### 3.1 Оптимальный прогноз

RMSLE — это MSE в шкале `log1p`, поэтому минимум достигается **условным средним
в лог-шкале**:

```
ŷ*(x) = expm1( E[ log1p(y) | x ] )
```

Лоссы, оптимизирующие `E[y|x]` (Tweedie, Poisson, Gamma), дают систематически завышенный
прогноз. Поправка Дуана (smearing), стандартная при лог-регрессии, здесь **вредна**.

**Подтверждено численно:** LightGBM Tweedie в сыром виде — 2,4401, Poisson — 2,4786
(хуже наивного бейзлайна). Те же модели после лог-калибровки — 1,869 и 1,884.
Прямой L2 по `log1p` — 1,691.

### 3.2 Точная двухстадийная декомпозиция

Поскольку `log1p(0) = 0`:

```
E[log1p(y) | x] = P(y > 0 | x) · E[ log1p(y) | y > 0, x ]
```

Это **тождество**, а не приближение: классификатор и регрессор перемножаются без
поправочных коэффициентов, в отличие от обычной hurdle-модели в исходной шкале.

## 7. Калибровочный аппарат

После первых трёх сабмитов вся дальнейшая работа велась аналитически.

### 7.1 Уровень

Для семейства `p_c = expm1(log1p(p) + c)` метрика — **точная парабола**:

```
RMSLE²(c) = R0² − 2·c·D + c²,   D = E[log1p(y)] − E[log1p(p)]
```

Три точки (`c = 0; 0,105; 0,190`) дали коэффициент при `c²` равным **1,000000** и две
независимые оценки `D`, совпавшие до шестого знака (0,10117 и 0,10117).

**Результат:** `E[log1p(y)]` на публичной выборке = **2,3284**. Сезонный сдвиг
относительно валидации — **+0,0863**. Оценка по календарному аналогу 2025 давала +0,176,
то есть была завышена вдвое: в неё подмешался фиктивный рост от критерия отбора.

Проверка: `two_stage` при трёх сдвигах после приведения к общему уровню дал
**1,6546852 / 1,6546822 / 1,6546798** — разброс 5·10⁻⁶.

### 7.2 Наклон

Для `p = expm1(b·log1p(p) + c)` при выровненном уровне:

```
R²(b) = Var(L) − 2b·Cov(L,P) + b²·Var(P)
```

Одна дополнительная точка (`b = 0,85`) разрешает систему:
**`b* = 1,0420`**, **`Cov = 2,53398`**, **`Var(L) = 5,366802`**.

`Var(L)` глобальна, поэтому из неё восстанавливается `Cov(L, Pᵢ)` для любого отправленного
вектора, а значит и его корреляция с таргетом.

### 7.3 Бленды и стеки

При выровненном уровне `Var(L)` сокращается, и скор бленда предсказывается **заранее**:

```
R²(w) = Σwᵢ·R*ᵢ² − ½ΣΣwᵢwⱼ·Var(Pᵢ − Pⱼ)
```

а при известной `Var(L)` — безусловная OLS-проекция `L` на линейную оболочку предсказаний.

**Точность предсказаний:**

| Сабмит | Предсказано | Факт | Ошибка |
|---|---|---|---|
| бленд двух | 1,6524709 | 1,6524999 | 2,9·10⁻⁵ |
| `ols_stack` | 1,650791 | 1,6508950 | 1,0·10⁻⁴ |
| `stack7` | 1,649364 | 1,6494144 | 7,4·10⁻⁵ |
| `stack9` | 1,649092 | 1,6491801 | 8,8·10⁻⁵ |

Единственный источник ошибки — ковариации считаются по всем 250 000, а лидерборд по
50 000 публичных. Устойчивость проверяется симуляцией на 80–100 подвыборках по 50 000.

**Правило полезности нового компонента:** он улучшит стек тогда и только тогда, когда

```
corr(L, новая) > corr(L, стек) · g,   g = corr(новая, стек)
```

Это позволяет заранее сказать, какой собственный LB-скор кандидату достаточен.

## 9. Четыре непереноса probe → лидерборд

Отдельный результат, важный для дальнейшей работы. На текущем уровне различий
валидационное окно **перестало упорядочивать модели**:

| Эксперимент | Δ на probe | Δ на лидерборде |
|---|---|---|
| v2-признаки (+126 фич) | −0,001 | ≈ 0 |
| RFE (296 → 41 признак, CatBoost) | −0,0092 | **+0,0012** |
| Сезонные якоря | +0,018 | не отправлялось |
| Без календарных признаков (CatBoost) | −0,0061 | **+0,0001** |

Причина, по-видимому, общая: любой отбор, сделанный по целевому окну
`2026-01-15 … 02-13`, привязывается к единственному сезонному провалу в году, а тест
приходится на подъём 23 февраля и 8 марта.

Что при этом **осталось предсказуемым** — вклад компонента в стек. Он считается
аналитически из корреляций и сбывается с точностью 10⁻⁵…10⁻⁴, что и подтверждено
четырьмя замерами подряд.

| MDME multi-expert | 1,9219 | 0,9978 | выигрыш в 5-м знаке |

Три sequence-модели скоррелированы между собой на 0,998–0,999: своё ортогональное
содержание это семейство внесло один раз.

### Стоимость следующего шага

Компонент типичного профиля (`g ≈ 0,996`, `corr ≈ 0,700`) добавляет **2–4·10⁻⁴**.
Чтобы взять ещё 0,001, нужно 4–5 новых моделей.

Отдельный риск: калибровка настроена по 50 000 публичных клиентов, а итог считается
по 200 000 приватных. Оптимизация пятого знака по паблику улучшает измеряемый результат
сильнее, чем ожидаемый.
