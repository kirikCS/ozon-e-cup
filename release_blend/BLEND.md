# Бленд `stack_daily` — компоненты, веса, расчётный скор

Расчётный RMSLE на публичном лидерборде: **1,647228**.
Для сравнения: лучший замеренный вектор команды на момент сборки — 1,6478432, 
официальный топ-1 — 1,6480488. Ожидаемый шаг **−0,00062**.

Прогноз получен аппаратом, а не оценён: историческая точность на тихих решениях 
2·10⁻⁵ … 1·10⁻⁴, и это решение тихое (max|w| = 0,577 при лимите 0,6, глубже −0,13 шортов нет).

## Как считается

Три величины измерены зондами лидерборда и дальше используются как константы:

```
E[log1p y] = 2,3284         из трёхточечной параболы сдвигов
Var(log1p y) = 5,366802     из зонда наклона
Cov(L, P) = (Var_L + Var(P) − R*²) / 2      точно, для любого замеренного вектора
```

Каждый вектор выравнивается по уровню `q − mean(q) + 2,3284`, после чего оптимальная 
линейная смесь — обычный ридж-OLS, а её скор предсказывается заранее:

```
R²(w) = Var_L − 2·wᵀk + wᵀCw,     k_i = Cov(L, P_i),  C = ковариация выровненных векторов
```

Вектор `k` дополнительно поправлен по реестру измеренных смесей: каждая отправленная и 
замеренная смесь даёт точное линейное ограничение `wⱼᵀδ = (R²изм − R²пред)/2` на ошибку `k`, 
и min-norm решение по четырём таким ограничениям вычитается из `k`. После поправки все 
четыре смеси репрайсятся точно до шестого знака.

Ридж: `1e-04`. Сумма весов 1.0062 — наклон учтён автоматически, 
отдельно применять не нужно.

## Новое в этом бленде

`daily` — дневная генеративная модель, вес +0,2432, третий по величине. Предсказывает не 
сумму за 30 дней, а путь: на каждый день горизонта выдаётся хазард покупки и распределение 
суммы при покупке, затем пути симулируются и берётся

```
ŷ = expm1( среднее по путям log1p( Σ_d y_d ) )
```
то есть `E[log1p Y|x]` — сам оптимум RMSLE, а не приближение к нему. Суммировать средние и 
логарифмировать после нельзя: разрыв Йенсена здесь измерен и равен **1,0906** в лог-шкале 
(наивная сборка даёт 2,48051 против 1,75495 у симуляции).

Зависимость дней внутри окна учтена общей latent-frailty на клиента: один `z ~ N(0, σ²)` 
на путь сдвигает хазарды всех дней этого пути. Дневные маргиналы сохраняются пробит-
перемасштабированием `logit' = logit·√(1 + πσ²/8)`. Параметр один, подобран на обучающих 
якорях по совпадению `P(Y>0)` (эмпирическая 0,5427 → σ = 0,8) и заморожен.

Интегрирование frailty квадратурой Гаусса-Эрмита (16 узлов) вместо её розыгрыша убрало 
основную часть дисперсии оценки: −0,0021 к локальному скору.

Локально на отборочном якоре: **1,74117** против 1,74216 у продакшн-LightGBM и 1,77127 у 
`seq_pure` — при том, что модель не видит ни одного из 165 табличных признаков.

```bash
python rebuild.py            # собирает stack_daily.csv из components/ и weights.json
```

`weights.json` содержит веса, собственные LB компонент и константы аппарата. 
`components/*.csv` — 17 векторов, каждый с собственным замеренным `R*`; все отсортированы 
по `user_id` и совпадают по порядку с `sample_submit.csv`.

## Оговорки

- В реестре ограничений у сокомандника пять записей, но файл `stack7_2s9seed_lb1649381.csv` 
в переданный архив не попал — поправка `k` посчитана по четырём. Оставшиеся четыре 
воспроизводятся точно.
- `ts_9seed` отправлялся на лидерборд с сырым уровнем (`mean log1p` = 2,2276). В таблице 
указан `R*`, приведённый к выровненному уровню: `√(1,6556581² − 0,1008²) = 1,6525868`. 
Смешение сырого и выровненного уровней в этой паре однажды исказило три решения подряд.
- Потолок задачи измерен: `corr(L, ·) ≤ 0,7039`, что даёт предел RMSLE **1,64550**. 
Этот бленд стоит на `corr = 0,70315`, то есть до предела остаётся около 0,0017.
